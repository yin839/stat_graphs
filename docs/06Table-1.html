6  出版级Table 1一键生成 | 可导出word直接投稿


临床研究写文章的第一关Table 1，还在用Excel手搓吗？

  • 复制粘贴，一个不留神就串行。
  • 剔除一个样本，所有统计量推倒重来。
  • 好不容易算完，转到Word一粘贴，格式全乱。

可能也试过R的tableone包，确实也很方便，但输出像 “毛坯房”，不够美观，自定义统计量和P值计算方法都受限制。今天跟大家分享一套组合拳：gtsummary + flextable。gtsummary负责统计，flextable负责美化，一步到位，直接生成出版级Table 1。

6.1 Table 1需要报告P值吗？

尽管从技术上讲，只需要在gtsummary中增加一行add_P()就可以输出P值，但在此之前，我们需要回答一个问题：Table 1到底是否需要放P值？

CONSORT声明指出：“不建议对基线差异进行显著性检验，也不应报告此类结果。这类显著性检验用于评估观察到的基线差异是否可能由偶然因素引起；然而，只要随机分组未被破坏或干扰，任何差异都可能是偶然造成的。”1由此可见，RCT的Table 1是不需要报告P值的。

在观察性研究中，组间基线特征往往存在不平衡，可能引入混杂偏倚，影响研究结果的可靠性。但STROBE声明指出：“标准误和置信区间等推断性指标不应用于描述特征的变异程度，描述性表格中应避免使用显著性检验。此外，P值也不是筛选分析中需要调整的混杂因素的恰当标准；即使某混杂因素组间差异很小，只要它对结局有较强的影响，也可能具有重要意义。”2可见在观察性研究中，一般情况下Table 1也不需要报告P值，除非期刊有明确的要求。

6.2 实例

加载必要的包：

library(tidyverse)
library(gtsummary)
library(flextable)

本例用到的模拟数据如Table 6.1所示，数据包含以下变量：

  • 标识变量：患者ID（id）、治疗组（group）
  • 特征变量：年龄（age）、性别（sex）、种族（race）、ECOG评分（ecog_score）、疾病类型（type）、ISS分期（iss_stage）、细胞遗传学风险（cytogenetic_risk）、自诊断至入组时间（time_since_diag）

这些特征变量正是我们要在table 1中展示的。

  • 第一步：用gtsummary计算统计量，增加特征变量的标签。

连续变量我们选择“中位数（最小值 - 最大值）”作为统计量，分类变量选择“数量（百分比）”。同时为每个变量增加统一格式的标签，例如连续变量“年龄”的标签为“Median age (range) — yr”，分类变量“性别”的标签为“Male sex — no. (%)”。

gtsummary生成的表格本身就已经很清晰，如Table 6.2所示：

tbl <- df |>
  tbl_summary(
    by = group,
    include = c(age, sex, race, ecog_score, type, iss_stage, cytogenetic_risk, time_since_diag),
    label = list(
      age = "Median age (range) \u2014 yr",
      sex = "Male sex \u2014 no. (%)",
      race = "Race \u2014 no. (%)",
      ecog_score = "ECOG performance-status score \u2014 no. (%)",
      type = "Type of measurable disease \u2014 no. (%)",
      iss_stage = "ISS disease stage \u2014 no./total no. (%)",
      cytogenetic_risk = "Cytogenetic risk \u2014 no. (%)",
      time_since_diag = "Median time since diagnosis of multiple myeloma (range) \u2014 mo"
    ),
    statistic = list(
      all_continuous() ~ "{median} ({min}\u2013{max})",
      all_categorical() ~ "{n} ({p})"
    ),
    digits = list(
      all_continuous() ~ c(1, 0, 0),
      all_categorical() ~ c(0, 1)
    ),
    missing = "no"
  ) |>
  modify_header(
    label = "**Characteristic**",
    stat_1 = "**Treatment A** \n(N = {n})",
    stat_2 = "**Treatment B** \n(N = {n})"
  ) |>
  remove_footnote_header(columns = c(stat_1, stat_2)) |>
  as_flex_table()
tbl
  • 第二步：用flextable进行美化。

在本例中，我们设置了字体、字号、文字对齐方式和上下间距、重新设定了列宽，然后增加了标题和脚标。最终生成的“Table 1”如Table 7.3所示。

font_family <- "Arial"
font_size <- 10
tbl_flex <- tbl |>
  font(fontname = font_family, part = "all") |>
  flextable::fontsize(size = font_size , part = "all") |>
  align(j = 1, align = "left", part = "all") |>
  padding(padding.top = 2, padding.bottom = 2, part = "all") |>
  width(j = 1, width = 8.5, unit = "cm") |>
  width(j = 2:3, width = 4.5, unit = "cm") |>
  set_caption(
    caption = as_paragraph(
      as_chunk(
        "Table 1. ",
        props = fp_text_default(bold = TRUE, font.family = font_family, font.size = font_size)
      ),
      as_chunk(
        "Characteristics of the Patients at Baseline (Intend-to-Treat Population).",
        props = fp_text_default(font.family = font_family, font.size = font_size)
      )
    ),
    fp_p = officer::fp_par(text.align = "left", padding.bottom = 8),
    align_with_table = FALSE
  ) |>
  footnote(
    j = 2:3,
    value = as_paragraph(
      as_chunk(
        "Patients assigned to group A received a quadruple regimen, while those in group B received the conventional triple regimen.",
        props = officer::fp_text(font.family = font_family, font.size = font_size)
      )
    ),
    ref_symbols = "*",
    part = "header"
  ) |>
  bg(i = seq(2, nrow(tbl$body$dataset), by = 2), j = NULL, bg = "#F7FBFF")
tbl_flex

gtsummary + flextable组合的一大优势是可以直接生成word格式的表格！运行flextable::save_as_docx(tbl_flex, path = "table_1.docx")即可在当前目录下生成相应的word文档。

只要我们提前设定好统计量和标签，调整好期刊要求的格式，就可以一键生成Table 1，直接用于投稿啦！
