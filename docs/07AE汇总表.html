7  告别耗时费力 | 快速生成符合规范的不良事件汇总表


不良事件（AE）汇总表是临床研究安全性结果的关键图表，准确与规范非常重要。

注册临床试验必须遵循ICH规范，采用《监管活动医学词典》（MedDRA）的标准化术语对不良事件进行编码1。MedDRA 采用五层术语层级：SOC（系统器官分类）→ HLGT（高位组术语）→ HLT（高位术语）→ PT（首选术语）→ LLT（最低层术语），其中SOC与PT是AE汇总表最相关的两个层级。

对于非注册临床研究（如IIT、观察性研究等），虽然不强制要求全套ICH合规，但推荐借鉴ICH的统计原则，确保结果可解释、可复现，提高研究的严谨性。

一张合格的AE汇总表，制作难度远比看上去要大。

  • 既要保证事件不遗漏，又要避免重复计数；
  • 以患者为单位统计，同一患者同一AE发生多次，只计1次；若多次事件严重程度不同，则取最高等级；
  • 样本量较大时，手动整理极易出错，耗时费力。

7.1 为什么推荐gtreg包？

gtreg包以gtsummary为后端引擎，可生成适合向监管机构提交的标准化表格2。它能够快速生成准确、规范的AE汇总表，具有以下优势：

  • 轻量简洁，适合非注册临床研究；
  • 原生支持MedDRA编码的SOC → PT层级结构；
  • 可直接导出Word格式，满足期刊投稿要求。

使用gtreg进行统计、flextable进行美化，gtreg + flextable可以直接生成出版级的AE汇总表。

tern包是面向临床试验监管表格和图形的R包，功能全面，也可生成符合监管要求的AE汇总表，但它主要适用于制药企业的注册申报场景，而且学习曲线相对较陡。

对于多数研究者而言，优先推荐gtreg包，它能够在满足准确性与规范性要求的前提下，以最少的时间成本生成符合期刊要求的AE汇总表。

下面我们结合实例来演示如何使用gtreg制作AE汇总表。

7.2 AE汇总表实例

加载必要的包：

library(tidyverse)
library(gtreg)
library(flextable)

本例用到的模拟数据如Table 7.1所示。原始数据包含了患者id（patient_id）、治疗分组（treatment_group）、不良事件分类（class）、不良事件（term）和级别（grade），然后我们在级别（grade）基础上增加了任何级别不良事件（any_grade）和3级以上不良事件（grade3_plus）两个变量。需要注意的是，gtreg包在汇总不良事件时，当同一患者出现相同不良反应的多条记录时，函数自动保留最高级别的那一条，确保每位患者同一AE只计数一次。因此，grade变量需设置为有序因子（ordered factor），以便函数正确识别。

  • 第一步：使用gtreg进行统计汇总，初步生成AE汇总表，如Table 7.2所示。
tbl <- df |>
  tbl_ae_focus(
    include = c(any_grade, grade3_plus),
    id = patient_id,
    ae = term,
    soc = class,
    strata = treatment_group,
    label = list(any_grade ~ "Any Grade", grade3_plus ~ "Grade 3 or 4"),
    statistic = "{n} ({p}%)",
    digits = c(0, 1)
  ) |>
  modify_spanning_header(
    c(stat_2_1_1, stat_2_1_2) ~ "**Treatment A**\n(N = {n})",
    c(stat_2_2_1, stat_2_2_2) ~ "**Treatment B**\n(N = {n})"
  )
single_term_class <- df |> distinct(class, term) |> count(class) |> dplyr::filter(n == 1) |> pull(class)
tbl$table_body <- tbl$table_body |>
  dplyr::filter(!(var_label == "ae" & label %in% single_term_class)) #如果class只有一个term，则不再显示term，避免重复
tbl <- tbl |>
  as_flex_table()
tbl
  • 第二步：使用flextable进行美化，生成最终的AE汇总表，如Table 7.3所示。
font_family <- "Arial"
font_size <- 10
tbl_flex <- tbl |>
  font(fontname = "Arial", part = "all") |>
  flextable::fontsize(size = font_size, part = "all") |>
  align(j = 1, align = "left", part = "all") |>
  padding(padding.top = 5, padding.bottom = 5, part = "all") |>
  width(j = 1, width = 5.5, unit = "cm") |>
  width(j = 2:5, width = 3, unit = "cm") |>
  set_caption(
    caption = as_paragraph(
      as_chunk(
        "Table 3. ",
        props = fp_text_default(bold = TRUE, font.family = font_family, font.size = font_size)
      ),
      as_chunk(
        "Most Common Adverse Event (Safety Population).*",
        props = fp_text_default(font.family = font_family, font.size = font_size)
      )
    ),
    fp_p = officer::fp_par(text.align = "left", padding.bottom = 8),
    align_with_table = FALSE
  ) |>
  add_footer_lines(
    "* The safety population included patients who had received at least one dose of the assigned treatment."
  ) |>
  flextable::fontsize(size = font_size, part = "footer") |>
  line_spacing(space = 0.8, part = "footer") |>
  bg(i = seq(2, nrow(tbl$body$dataset), by = 2), j = NULL, bg = "#F7FBFF")
tbl_flex

通过gtreg + flextable组合我们可以得到准确、规范且美观的AE汇总表，并且可以直接导出word。运行flextable::save_as_docx(tbl_flex, path = "table_ae.docx")即可在当前目录下生成相应的word文档。

终于可以告别耗时费力的手动整理，用最短的时间快速生成符合规范的不良事件汇总表啦！
